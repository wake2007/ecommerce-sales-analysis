# 数据说明：UCI Online Retail

## 一、数据来源

- 名称：Online Retail（英国在线零售商交易流水）
- 来源：UCI Machine Learning Repository，Dataset 352
    https://archive.ics.uci.edu/dataset/352/online+retail
- 规模：541,909 行 × 8 列
- 时间跨度：2010-12-01 08:26 ~ 2011-12-09 12:50（约 12 个月）
- 数据粒度：一行 = 一笔订单中的一种商品（一个订单可含多行）

## 二、字段说明

| 列名          | 中文含义 | 类型   | 特别注意                                  |
|-------------|------|------|---------------------------------------|
| InvoiceNo   | 订单号  | 文本   | C 开头 = 取消/退货单（9,288 行）；A 开头 = 坏账调整（3 行） |
| StockCode   | 商品编号 | 文本   | 不全是 5 位数字，有 POST/M/D/B 等特殊码，不是商品      |
| Description | 商品名称 | 文本   | 1,454 个空值：862 行数量为负（库存调整）、592 行数量为正但零价无客户。空描述≈“非正常销售”的标志，但不是漏填                  |
| Quantity    | 数量   | 整数   | 负数 = 退货或库存调整，共 10,624 行               |
| InvoiceDate | 下单时间 | 日期时间 | 只精确到分钟（秒全是 0）                         |
| UnitPrice   | 单价   | 小数   |单位英镑 £。共 2,517 行 ≤ 0：< 0 只有 2 行（坏账调整  -11,062.06）；= 0 共 2,515 行，其中 1,336 行数量为负（库存盘亏）、1,179 行数量为正（赠品/样品/内部调剂）。都不是正常销售                 |
| CustomerID  | 客户编号 | 小数   | 24.93% 为空（135,080 行），游客下单无 ID         |
| Country     | 国家   | 文本   | 共 38 国，英国占 91.4%                      |
**客单价 532.64 英镑对零售而言偏高**：该零售商客户中批发商占比大
（数据集说明：Many customers of the company are wholesalers），
单次采购量远超普通零售客户。
## 三、四条必须记住的事

1. 一行 = 一单里的一个商品。所以54万行只对应2.59万张单子。
2. StockCode不都是五位数。POST（邮费）、M（手工录入）、D（折扣）、B（坏账调整）、DOT（网站订单邮费）...
这些不是商品，是做账用的特殊码。后面做“畅销商品”时要注意别把“邮费”当商品排进去。
3. 没有成本字段。表中只有售价，没有进价。所以本项目只能算销售额，不能算利润。
4. 时间跨度 2010-12-01 至 2011-12-09，约 12 个月，不是完整两个年度。
所以能做月度趋势、季节性，但做不了"年度同比"。
